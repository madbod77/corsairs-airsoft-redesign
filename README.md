# CORSAIRS — страйкбол Київ

[Відкрити сайт](https://madbod77.github.io/corsairs-airsoft-redesign/) · [Офіційний клуб](https://airsoft.corsairs.com.ua/) · [Instagram](https://www.instagram.com/strikeball_corsairs_kiev/)

Готовий адаптивний редизайн головної Corsairs на HTML, CSS та JavaScript. Фотографії клубу, українська мова, локальні Manrope і Roboto Condensed, формати ігор, підбір гри, галерея, FAQ і контакти.

## Запуск

Відкрийте `index.html` у браузері або запустіть `python3 -m http.server 4190` у теці проєкту та перейдіть на http://localhost:4190/. Інсталяція й збірка не потрібні.

GitHub Pages публікує корінь гілки `main`; `.nojekyll` зберігає статичні файли без обробки Jekyll.
